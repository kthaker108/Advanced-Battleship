1. Project Title and Description
My project is called Advanced Battleship and it follows the traditional boardgame/video game "Battleship". 
However, in my game, I have added four upgrades the player can purchase with their points to enhance the depth
and user interactiveness in the game. The goal is to beat the computer AI that you are playing against!


2. Run Instructions
Simply run the main.py file. No external libraries/modules needed!

3. Shorthand Commands
can toggle in between pages so you don't need to wait for the whole process to be done to get to another page:
p = ship screen
h = selection screen 
s = shop screen
t = tutorial screen
